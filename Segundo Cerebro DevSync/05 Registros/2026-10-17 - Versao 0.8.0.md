# 🚀 Versão 0.8.0 — AI Morning Catch-Up & HUD Spotlight Command Palette

Marco evolutivo focado na fluidez da alternância diária entre ambientes (Casa vs Trabalho) e na produtividade contínua do desenvolvedor através de inteligência contextual e acesso instantâneo via Command Palette.

## 🌟 As Inovações Entregues na v0.8.0

### 1. AI Morning Catch-Up & Retomada de Contexto
- **Briefing Executivo Matinal:** Ao abrir o DevSync no início da jornada ou mudar de máquina (Casa ↔ Trabalho), o motor analisa os últimos commits recebidos e enviados, extraindo os pontos críticos alterados no código.
- **Detecção de Pendências Técnicas nos Diffs:** Varredura automática nas linhas modificadas procurando anotações de código pendentes (`TODO:`, `FIXME:`, `HACK:`, `BUG:`, `XXX:`), listando-as de imediato para não deixar trabalho inacabado para trás.
- **Formulação de Próximos Passos:** Síntese em linguagem natural dos próximos passos recomendados para guiar o desenvolvedor na retomada imediata do foco.
- **Integração com Obsidian:** Persistência automática no diário de bordo sob o cabeçalho `## 🌅 Resumo Matinal & Retomada de Contexto (<Projeto>)` em `Segundo Cerebro DevSync/05 Registros/YYYY-MM-DD - Resumo Diario.md`.
- **Motor Híbrido:** Geração semântica com Google Gemini AI e fallback 100% determinístico (`heuristicCatchUpSummary`) quando `GEMINI_API_KEY` não estiver presente.
- **CLI & MCP:** Acionável via terminal por `devsync catch-up [id]` e por agentes de IA via ferramenta MCP `devsync_catch_up`.

### 2. HUD Spotlight Command Palette & Instant Switcher
- **Evolução da Pílula Flutuante:** A janela translúcida frameless agora opera em dois modos integrados com transição suave e redimensionamento dinâmico via IPC nativo (`set-hud-size`):
  1. *Modo Compacto (320x52 px):* Pílula discreta com indicador de status, contagem de pendências, sincronização rápida e botão expansor de busca.
  2. *Modo Spotlight Palette (460x420 px):* Launcher estilo Raycast/Spotlight com busca fuzzy instantânea em todos os projetos cadastrados.
- **Atalhos Ultra-Rápidos de Teclado:**
  - `Enter`: Sincroniza o projeto em foco imediatamente.
  - `Alt+C`: Abre a pasta do projeto diretamente no VS Code (`code <pasta>`) via IPC nativo seguro.
  - `Alt+G`: Abre o repositório remoto no GitHub pelo navegador padrão do sistema.
  - `Alt+D`: Abre o painel local na tela de inspeção de alterações e Diffs.
  - `Esc`: Contrai a Command Palette de volta para a pílula compacta.
- **Aba "🌅 Catch-Up Matinal" Integrada:** Permite ler o briefing executivo e pendências do dia diretamente de dentro do HUD flutuante, sem precisar abrir o painel completo.

### 3. Expansão MCP para 17 Ferramentas Corporativas
- Servidor MCP nativo (`devsync mcp`) expandido com `devsync_catch_up`, totalizando 17 ferramentas disponíveis para agentes externos (Claude Code, Cursor, Antigravity).
