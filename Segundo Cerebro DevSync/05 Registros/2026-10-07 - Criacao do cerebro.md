# 🗓️ 2026-10-07 — Criação do cérebro

## Objetivo

Criar um segundo cérebro do DevSync no Obsidian, explicando o projeto e seu uso.

## Base da documentação

Código da versão 0.3.0, commit `82127ea`, README, decisões arquiteturais, guias remoto/deploy e relatório de validação.

## Resultado

Foi organizada uma base navegável com guias de operação, mapa da arquitetura, diagnóstico, fontes, modelos e mapa Canvas. O conteúdo diferencia implementação de publicação e testes reais de evidência registrada.

A pasta é um cofre próprio dentro do projeto. Não foi mesclada aos cofres existentes e não contém credenciais.

## O que ainda precisa acontecer

Abrir a pasta como cofre no Obsidian; seguir [[02 Uso/Primeiros passos]] e registrar uma sessão real. Para uso remoto pela internet, concluir [[03 Engenharia/Hospedagem e operacao]].

## Aprendizados que precisam permanecer visíveis

- Link GitHub vai na clonagem; cadastro usa pasta local.
- Salvar, criar commit e enviar são etapas diferentes.
- Checkpoint e push são permissões independentes.
- Arquivos novos exigem commit manual.
- O coordenador não transporta código.
- Publicar instalador não publica coordenador.
- Tokens devem ficar fora das notas.
