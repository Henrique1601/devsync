# 🚀 Registro de Release — DevSync v0.6.0

## Contexto e Objetivos

Nesta evolução supervisionada pelo **Agente Global Supremo**, o DevSync avançou para a versão **0.6.0 (Master Upgrade)**, implementando as inovações corporativas solicitadas pelo usuário:

1. **Zero-Leak Pre-Commit Secret Scanner (`src/secrets.js`):** Motor de varredura pré-commit baseado em regras estritas que detecta chaves privadas (RSA/EC/PGP), tokens GitHub (`ghp_`, `github_pat_`), chaves de acesso AWS (`AKIA`), chaves Gemini/Google API (`AIzaSy`), chaves OpenAI/Anthropic e webhooks sensíveis (Discord/Slack). Bloqueia preventivamente a criação de checkpoints automáticos se segredos forem detectados no diff.
2. **Resolução Semântica de Conflitos com IA & Heurística (`src/ai.js`):** Motor inteligente de reconciliação de código que aciona a API Gemini (`gemini-2.5-flash`) quando `GEMINI_API_KEY` estiver configurada, com fallback determinístico robusto (`heuristicMerge`) que remove marcadores Git e preserva alterações exclusivas sem depender da rede.
3. **Interface Visual & Editor 3-Way de Conflitos na UI Local:** Modal interativo ampliado com 3 painéis: Código Local (HEAD), Código Remoto (Incoming) e Editor Mesclado em tempo real, permitindo ao usuário revisar, editar e salvar a resolução com um único clique.
4. **Atalhos Globais de Sistema (Windows Desktop):** Atalho global `Ctrl+Shift+S` para acionar a sincronização em lote de todos os projetos ativos com notificação nativa, e `Ctrl+Shift+D` para focar a janela do DevSync instantaneamente.
5. **Sincronização & Envio de Git Tags:** Suporte completo à sincronização de tags via `--tags` no fetch e no push, garantindo total paridade de versões e releases entre Casa e Trabalho.
6. **Expansão do Protocolo MCP para Agentes de IA:** Expansão para 12 ferramentas MCP corporativas (`devsync_scan_secrets`, `devsync_ai_resolve_conflict`, `devsync_resolve_conflict`), transformando o DevSync em um hub operacional para agentes autônomos.
