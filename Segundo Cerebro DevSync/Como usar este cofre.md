# 📚 Como usar este cofre

Este segundo cérebro é uma pasta de notas Markdown com navegação própria. Ele pode ser lido sem extensões da comunidade.

## Abrir no Obsidian

1. Abra o gerenciador de cofres do Obsidian.
2. Escolha **Abrir pasta como cofre** / **Open folder as vault**.
3. Selecione `C:/Users/henri/Programacao/Projetos/devsync/Segundo Cerebro DevSync`.
4. Abra [[00 Comece aqui]].

A criação desta pasta não registra automaticamente o cofre no aplicativo. Seus outros cofres continuam separados.

| Pasta | Conteúdo |

| 06 Modelos | Estruturas para criar registros |
| 07 Referencias | Glossário e fontes |
| 08 Anexos | Evidência visual do aplicativo |

## Navegar e registrar

- Clique em um link para seguir uma conexão; os backlinks mostram quais notas citam a nota atual.
- Use **Ctrl+O** para localizar uma nota pelo título e **Ctrl+P** para abrir a paleta de comandos.
- Abra [[00 Mapa do conhecimento.canvas]] para uma navegação espacial.
- Para registrar trabalho, crie uma nota em `05 Registros` e use o comando **Templates: Insert template** / **Modelos: inserir modelo**. Também pode copiar um modelo manualmente.
- Para uma nota diária, use o comando de notas diárias; o modelo [[06 Modelos/Sessao de trabalho]] já está configurado.

Exemplo de link entre suas notas: `[[02 Uso/Checkpoints e regras]]`. Os arquivos já usam caminhos completos dentro do cofre para evitar ambiguidade.

## Manter útil

Primeiro capture a dúvida na [[05 Registros/Caixa de entrada]]. Depois transforme a solução numa nota relacionada e marque a dúvida como resolvida. Faça uma revisão semanal dos pendentes.

O estilo visual usa um snippet local, desativável em Aparência. Modelos, Canvas, grafo e notas diárias usam recursos nativos. Nenhum plugin de comunidade foi instalado.
