# 📖 Glossário

| Termo | Significado neste projeto |
| --- | --- |
| Clone | Cópia local de um repositório Git |
| Repositório | Arquivos e histórico controlados pelo Git |
| Branch | Linha de desenvolvimento; o cadastro fixa uma para o projeto |
| HEAD | Commit atualmente selecionado |
| Upstream | Branch acompanhada pelo clone, como origin/main |
| Commit | Registro de uma mudança no histórico |
| Staged/índice | Alterações selecionadas para um commit manual |
| Untracked | Arquivo novo ainda não rastreado pelo Git |
| Fetch | Busca informação e commits do remoto |
| Fast-forward | Avança a branch para um descendente sem combinar históricos |
| Push | Envia commits locais ao remoto |
| Ahead | Há commits locais exclusivos |
| Behind | Há commits do upstream ainda não recebidos |
| Divergência | Local e upstream têm commits exclusivos |
| Checkpoint | Commit automático optativo de arquivos já existentes e permitidos |
| Daemon | Serviço que executa e coordena o trabalho no PC |
| Bandeja | Área de ícones do Windows onde o aplicativo continua ativo |
| Coordenador | Servidor remoto para estado de PCs e pedidos |
| Heartbeat | Consulta periódica que comunica o estado do PC |
| Ack | Confirmação do resultado de um pedido remoto |
| Token | Credencial de acesso, que fica fora deste cofre |
| Lock | Marca de propriedade usada para evitar trabalho simultâneo |
| Feed de atualizações | Pasta HTTPS com manifesto e instaladores |
| Blockmap | Metadados usados pela biblioteca de atualização |
| Checksum | Hash que permite detectar arquivo diferente do manifesto |

Conecte os termos ao uso em [[01 Projeto/Visao do projeto]], [[02 Uso/Historico e estados]] e [[03 Engenharia/Arquitetura]].
