Como sincroniza

Verificação a cada 30 segundos. Recebe atualizações com avanço direto do histórico. Operações Git em andamento e históricos divergentes pausam a sincronização. Envio de commits e checkpoints são ativados separadamente em cada projeto.

Checkpoints criam commits de arquivos já rastreados após um período sem alterações. Arquivos novos precisam ser adicionados pelo Git. Confira o .gitignore antes de ativar.
